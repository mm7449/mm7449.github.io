擺線針輪(賽驅樂)減速機 計算器

輸入條件

此模式以上方「軸承最大外徑」作為上限檢查(外滾柱最大外徑 = 中心圓直徑 + 外徑);針徑比 q 不使用。
輸入 e 後會換算成 K1 = e·N / Rp(K1 範圍 0.10～0.98);拖曳 K1 滑桿時此欄會同步更新。
最佳解 = 通過全部檢查（含偏心上限與齒型平順）；未勾「最小偏心」取餘裕最大，勾選時在平順解中取最小偏心。
檔案以 zip 封裝,解壓後取得 .dxf / .step;需所有檢查全部通過才能匯出;擺線盤輪廓在 DXF 與 STEP 中都是單一封閉平滑曲線(STEP 為 B-spline 曲面,非小平面);兩處記號：①偏心後擺線盤中心 (e,0)（discQ 有 +e 平移，不是固定座標原點）②齒頂中心圓上的齒頂。DXF: TIPMARK; STEP: DISC_CENTER / TIP_CENTER。

公式

外滾柱數 N = i + 1 擺線盤齒數 Z = N − 1 = i 偏心距 e = K1·Rp / N 外滾柱分佈圓半徑 Rp = (Db/2) / (1 + q·sin(π/N)) 外滾柱半徑 rp = q·Rp·sin(π/N) 外滾柱最大外徑 Dp = 2·(Rp + rp) ≤ Db 擺線盤齒廓(t = 0 ~ 2π): ψ = atan2( sin((1−N)t), 1/K1 − cos((1−N)t) ) x = Rp·cos t − rp·cos(t+ψ) − e·cos(N·t) y = −Rp·sin t + rp·sin(t+ψ) + e·sin(N·t) 理論曲線曲率半徑 ρ(凸處)≥ rp → 無過切、滑順 干涉:各針中心至齒廓距離 − rp ≥ 0 運動:輸入軸轉 θ,擺線盤自轉 −θ/(N−1) 反推:已知 Rp、rp、N=i+1 → e = K1·Rp/N,掃描 K1 找出同時滿足曲率、干涉、槽保持、偏心上限的範圍 齒頂圓 Da = 2(Rp+e−rp),齒根圓 Df = 2(Rp−e−rp),齒深 = 2e V3:可設 e_max 上限;可調齒型平順門檻 ρmin/rp(預設1.25) 「嚴格避免偏尖」開啟時未達門檻視為不合格;「最小偏心優先」在平順解中取最小 e 齒型檢測: ρmin < rp → 過切; ρmin/rp < 1.25 → 偏尖(建議降 K1 或略增 q)
短幅係數 K1 怎麼選（e = K1·Rp / N，齒深 = 2e）
0.45～0.60齒淺、齒尖圓鈍、不易過切。要小偏心、平順低噪音、好加工時用。
0.60～0.75齒深與尖銳度較平衡。一般減速機多落在這裡。
0.75～0.85齒較深、理論承載較高，齒頂開始變尖。要較大力矩且檢查仍過關時用。
> 0.85齒頂容易偏尖，ρmin 接近針半徑。通常不建議；嚴格模式會判不合格。
要平順：K1 往下，或勾「最小偏心優先」（在 ρmin/rp ≥ 1.25 內取較小 K1）。要較大齒深：檢查全過再把 K1 往上，且不要超過 e_max。已有偏心上限時 K1 ≤ e_max·N / Rp。實務常用 0.55～0.75。
