⚙️ 斜齒輪參數計算
(含轉位係數 + CAD 咬合直徑)

本齒輪參數
正轉位 x > 0，負轉位 x < 0
配對齒輪（CAD 咬合用，可選）
1. 本齒輪幾何尺寸
節圓直徑 (d₁) 參考
d = Z·Mn / cos(β)　(不受 x 影響)
基圓直徑 (db)
db = d·cos(αt)
齒頂圓 (da)
齒根圓 (df)
齒冠高 (ha)
|da - d| / 2
齒全高 (h)
|da - df| / 2
紅虛線: 節圓 / 綠虛線: 基圓
2. 轉位係數分析
轉位係數 (x₁)
刀具偏移 = x · Mn
分度圓齒厚 (s)
s = Mn·(π/2 + 2x·tan(αn))
當量齒數 (zv)
zv = Z / cos³(β)
最小轉位係數 (xmin)
xmin = 1 − zv·sin²(αn)/2
3. CAD 咬合直徑與中心距 ★
標準中心距 (a₀)
a₀ = (d₁ + d₂)/2
實際中心距 (a)
a = a₀ · cos(αt)/cos(αw)
工作節圓直徑 dw₁ (咬合)
dw₁ = 2a · Z₁/(Z₁+Z₂)
工作節圓直徑 dw₂ (咬合)
dw₂ = 2a · Z₂/(Z₁+Z₂)
工作壓力角 αw
由 inv(αw) 反算
總轉位係數 Σx
x₁ + x₂
CAD 繪圖建議：
• 兩個齒輪的咬合直徑請使用 dw₁ 與 dw₂（而非參考節圓 d）
• 中心距請使用實際中心距 a
• 參考節圓 d 仍用於定義基圓與漸開線
4. 測量數據 (跨齒厚 & 跨銷法)
跨銷法 (Over Pin)
量銷直徑 (dp)
跨銷尺寸 (M)
跨齒厚 (Span)
跨測齒數 (k)
跨齒厚度 (W)
實線顯示量銷在齒槽中的位置
